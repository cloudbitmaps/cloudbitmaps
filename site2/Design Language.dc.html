Everything on this page is a rule you can re-implement.

Palette, type, spacing, components and motion — all derived from the blue→cyan ramp already in the logo, so the mark stops looking pasted on. Both themes are designed, not inverted. Nothing here needs a CDN, a webfont, or a build step.

02

Palette — six values, two themes

The ground is a cool graphite pulled toward the mark's blue (hue ≈ 250 in oklch, chroma under .01) rather than a neutral black — so the ramp sits in the page instead of on it. Signal blue is the mark's own #176FFF; cyan is its #19C5F4. Light theme is redrawn, not inverted: both accents darken to hold 4.5:1 on paper, which inversion would never have given you.

03

Type — one grotesque, one mono, zero downloads

Helvetica Neue does the display and the body; the platform mono does every figure, key, unit and label. Not Inter, not Space Grotesk, and nothing to embed as a data URI — which is the only way “no external anything” is honestly satisfiable. Character comes from the setting: display runs at −0.035em tracking and 1.02 leading, labels at +0.14em uppercase mono, and the two never meet in the middle.

04

Layout — hairlines, not cards

A 12-column grid on a 1240px measure, 32px gutters. Structure is expressed with 1px rules and shared edges — panels butt against each other like instrument bezels. No drop shadows, no border-radius above 3px, and no accent bar on every card.

06

Motion — three views of one true statement

Composed together these are the centrepiece of /architecture: chunk-skipping intersection over tiered storage. Intersecting two 2,000,000-id segments fetches only the ~100 shared chunks of 2,000 and leaves the rest cold — codec-independent, so it stays true when bitmap ships. Nothing else on the site moves. With prefers-reduced-motion set, each view holds its final frame and stays readable.

06b

The per-flavor codec slot — same four stages, different stage 03

Every flavor page carries exactly one animation, and it explains only its own codec. Both run the same 12-second, four-stage frame — split → group → represent → store — because stages 01, 02 and 04 belong to the engine and are identical by definition. Only stage 03 differs, which is precisely the thing a reader is choosing between. Building the next flavor's animation is therefore filling one row, not designing a diagram.
