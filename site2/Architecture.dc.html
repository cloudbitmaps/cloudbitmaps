Architecture · codec-independent

A ∩ B fetches only the chunks that can possibly contribute.

Every id is split into a 16-bit chunk key and a 16-bit remainder. The key is metadata, the remainder is payload, and the two live apart — which is the whole trick. Intersecting two 2,000,000-id segments compares keys first and fetches only the ~100 shared chunks of 2,000, in 25.3 ms. The other 1,900 are never requested and never billed. None of this depends on the codec, so it stays true for every flavor.

The three tiers, and what each one is for

A segment is not moved between tiers — it exists in all three at once, and a read is resolved from the cheapest tier that can answer it.

TIERROLECOST SHAPE
HOT · RAM A bounded LRU of decoded chunks in your own process. Optional and evictable — correctness never depends on it, only latency. your memory, your call
WARM · NoSQL Per-chunk delta rows holding adds and removes since the last publish. A write touches one small row instead of rewriting a chunk — this is why writes cost $0.75 per million rather than $5.88. per request, metered
COLD · .crbm Immutable, generation-keyed objects in your bucket. Never mutated in place, so a reader always sees a consistent generation and an old one can be kept as a snapshot. $0.03/mo per 1.2 GiB

Compaction

Deltas accumulate; reads get slower and warm storage gets fuller. Compaction folds them into a new cold generation and drops the rows. It is a background job you schedule — not a stop-the-world event, and not something the read path waits on.

publish cost: $5.88 / 1M segments — batch it

Exact counts, zero payload reads

Cardinality per chunk is stored beside the chunk key, so count() sums metadata and never opens a payload. It is exact, not estimated — no HyperLogLog, no error bars.

1M counts: $0.14

What this design costs you

Every architecture is a set of trades. These are ours, stated where the diagram is.

01

A warm round trip is milliseconds, not microseconds. Measured in-region on 2026-07-27: p50 5.27 ms, p99 12.71 ms (n=2,000). That is “inside budget” for most request paths and disqualifying for some.

02

Sustained high write rates lose to a flat node. Past 26.33 writes/s the metered bill overtakes $346/mo. See the crossover.

03

Compaction is an operational responsibility. Skip it and reads degrade. It is a scheduled job you own, like a vacuum.
